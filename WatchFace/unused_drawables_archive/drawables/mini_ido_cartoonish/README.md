# Mini Ido Cartoonish Assets

Second avatar direction: more detailed, rounded, and cartoon-like than the pixel sprite set.

These are saved separately so the current watch-face implementation can keep using the first pixel-style option while this style is evaluated.

Files:

- `mini_ido_cartoon_neutral.svg`
- `mini_ido_cartoon_proud.svg`
- `mini_ido_cartoon_soft.svg`
- `mini_ido_cartoon_sleepy.svg`

Design cues:

- Close-cropped hairline
- Expressive eyes and strong eyebrows
- Short salt-and-pepper beard shape
- Lean runner build
- Black everyday outfit for neutral states
- White cap, sunglasses, lime shirt, blue hydration vest, bib, black shorts, and pink socks for the proud runner state
