# Mini Ido Badge Assets

This folder follows the latest supplied reference image more closely than the earlier exploratory styles.

The direction is a polished cartoon runner avatar inside circular mood badges:

- `mini_ido_badge_happy.svg`
- `mini_ido_badge_sleepy.svg`
- `mini_ido_badge_proud.svg`

Notes:

- These assets intentionally keep the badge framing from the reference image.
- The text labels from the reference image are not baked into the SVGs, so the watch face can decide whether to show mood text separately.
- The proud asset keeps bib `359`, matching the running reference.
- This set currently has three moods because the supplied reference contains happy, sleepy, and proud.
