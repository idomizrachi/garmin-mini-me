# Unused Drawables Archive

This folder contains image assets moved out of the active watch-face drawable set.

Active Garmin resources remain in `WatchFace/resources/drawables/` and are the only
files referenced by `WatchFace/resources/drawables/drawables.xml`.

Nothing here is deleted; restore an asset by moving it back under
`WatchFace/resources/drawables/` and adding a matching bitmap entry to
`drawables.xml` if the app should load it.
