# 454px original watch face backgrounds

`WatchFace/resources`.

Versions kept here:

- `watchface_backgrounds_avatar_bottom_left/*.png`: original full-color 454px backgrounds.
- `watchface_backgrounds_avatar_bottom_left/p256/*.png`: 256-color 454px backgrounds.
